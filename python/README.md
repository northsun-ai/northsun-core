# northsun

`northsun` is the Python package namespace for [Northsun](https://northsun.ai).

Version `0.0.1` intentionally reserves the package name while the production
Python SDK is prepared. It provides no product API yet.

```sh
northsun
```

For the product and documentation, visit [northsun.ai](https://northsun.ai).
