# @northsun-ai/core

`@northsun-ai/core` is the public package namespace for [Northsun](https://northsun.ai).

Version `0.0.1` intentionally reserves the `northsun` executable name while the
first production SDK is prepared. It provides no product API yet.

```sh
npx @northsun-ai/core --version
```

For the product and documentation, visit [northsun.ai](https://northsun.ai).
